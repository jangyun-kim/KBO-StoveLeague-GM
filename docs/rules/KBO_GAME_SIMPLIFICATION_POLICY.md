# KBO Game Simplification Policy (게임 단순화 정책)

## 1. 목적과 원칙

목표는 "현실고증이 미친 게임"이라는 평가다. 그러려면 **규정의 결과는 현실과 똑같이** 나오되, **규정을 다루는 수고는 플레이어에게 넘기지 않아야** 한다.

1. **결과는 현실 그대로** - 보상 비율, 등급 기준, 상한액, 지명 라운드, 엔트리 인원 같은 숫자는 원문 값을 쓴다(`KBO_OFFSEASON_RULES.md`).
2. **계산과 서류는 시스템이** - 등록일수 세기, 보상금 계산, 명단 제출 기한, 세금계산서 같은 일은 자동 처리하고 결과만 보여 준다.
3. **판단은 플레이어가** - 누구를 잡고 누구를 내보낼지, 돈을 얼마나 쓸지, 위험을 감수할지는 단장이 직접 고른다.
4. **공식 규정과 게임 규칙은 분리** - 코드에서도 `공식 규정 값(데이터) → 게임 적용 정책 → 게임 상태 변화` 세 층을 섞지 않는다.

## 2. 적용 단계

| 단계 | 의미 | 게임 내 적용 |
|---|---|---|
| **R1** | 플레이어 직접 결정 | UI에서 선택(계약 제시, 보호선수 지정, 지명, 승인/거절 등) |
| **R2** | 시스템 자동 처리 | 백그라운드 계산·상태 전이, 결과는 알림·대시보드로 표시 |
| **R3** | 초기 버전 생략 | 행정·법률 절차. **생략해도 "현실에는 있다"는 사실은 이 문서와 도움말에 남긴다** |

## 3. 위반 처리 3유형

| 유형 | 의미 | UI 처리 |
|---|---|---|
| **BLOCKED** | 규정상 불가능한 행동 | 버튼 비활성 + 툴팁에 게임 문장으로 사유("외국인 선수는 3명까지 보유할 수 있습니다.") |
| **WARNING** | 가능하지만 위험한 행동 | 확인 팝업에 예상 결과 표시 후 단장이 감수하면 진행 |
| **PENALTY** | 가능하지만 자동 제재가 붙는 행동 | 실행 전 예상 제재액·지명권 하락 표시, 실행 즉시 또는 결산 시점에 자동 부과 |

## 4. 제도별 단순화 정책

### 4.1 FA (KBO-OFFSEASON-001)
- **R1:** 우리 FA 잔류 협상 / 외부 FA 계약 제시 / 원 소속구단일 때 **보상 방식 선택(선수+현금 vs 현금)** · 보상선수 지명 / 획득 구단일 때 **보호선수 20·25명 지정**.
- **R2:** FA 자격 판정(8·7시즌, 145일 등록일수, 다년계약 유보, 재자격 4시즌) / **A·B·C 등급 자동 산정**(최근 3년 평균 연봉의 구단·리그 순위) /
  35세 이상 150% 특례 / 보상금 정산 / 보상 순서(계약 순 · 같은 날이면 성적 역순) / 보호 명단 자동 제외 대상(군보류·외국인·신인 등) /
  AI 구단의 FA 영입·보상선수 선택 / 3년 미계약 → 자유계약 전환.
- **R3:** FA 신청서 접수(공시 2일 이내), KBO 서면 제출, 세금계산서·지연이자.
- **위반 처리:** 외부 FA 영입 한도(1~4명) 초과 = **BLOCKED** / 외부 FA 1년 내 트레이드 = **BLOCKED** / 보상 이후 예산 부족 = **WARNING**.

### 4.2 경쟁균형세 (KBO-OFFSEASON-002)
- **R1:** 예외 선수 1명 지정 / 상한 초과를 감수할지 결정.
- **R2:** 상위 40명 자동 추출(외국인·신인 제외, FA 연평균 계약금 포함, 다년계약 평균) · 예외 선수 50% 차감 · 연속 초과 횟수 누적 ·
  제재금 산정 · 3회 연속 시 1라운드 지명권 9단계 하락 · 2027년부터 하한액.
- **[GAME-SIMPLIFIED]** 현실은 12월 15일 통보·1월 31일 납부지만, 게임은 **계약 화면에서 "계약 후 예상 경쟁균형세"를 실시간 표시**하고
  실제 부과는 스토브리그 결산 턴(12월 15일 상당)에 한 번 한다(DECISION-003 개정 제안 참조).
- **위반 처리:** 상한 초과 계약 = **PENALTY**(하드캡이 아니라 사치세). 제재금을 낼 운영 자금이 없으면 = **BLOCKED**.

### 4.3 2차 드래프트 (KBO-OFFSEASON-003)
- **실시 연도:** 현실과 같은 **격년(홀수 해: 2027 · 2029 …)**. 2026 부임 시점의 2025년 2차 드래프트는 이미 끝난 것으로 본다.
- **R1:** 35인 보호명단 지정(시스템이 추천안 제시) / 라운드별 지명 또는 패스.
- **R2:** 입단 1~3년차·당해 FA·외국인 자동 제외 / 한 구단 4명 지명 제한 / 하위 3팀 추가 지명 / 양도금 정산 /
  의무 등록 일수 백그라운드 카운트(부상자 명단 포함, 30일 이상 부상 시즌 면제) / 미충족 시 원 소속 복귀 + 양도금 50% 반환 / 1년 재양도 금지.

### 4.4 포스팅 (KBO-OFFSEASON-004)
- **[GAME-SIMPLIFIED]** 고정 턴이 아니라 **조건부 이벤트**: 7시즌 이상 + 해외 진출 희망 선수가 있을 때 11월 1일~12월 5일 창에서 팝업.
- **R1:** 포스팅 승인/거절(구단당 연 1명). 거절 시 선수 만족도 하락.
- **R2:** MLB 구단(AI) 관심도·제시 계약 생성, 30일 교섭 결과, 구간별 이적료(20% / 17.5% / 15%) 계산·예산 편입.
- **R3:** 의료기록 제출, 미 동부시간 기준 마감.

### 4.5 트레이드 (KBO-OFFSEASON-005)
- **R1:** 선수 ↔ 선수, **선수 ↔ 신인 지명권(2명 이내)** 교환 제안·수락.
- **R2:** 양도 가능 기간 판정(포스트시즌 종료 다음 날 ~ 7월 31일) / 개별 양도 금지(외부 FA 1년 · 2차 드래프트 1년 · 지명 신인 1년) /
  연봉 승계 / 이사비 양 구단 각 100만 원 자동 지출 / 7월 31일 이후 이적 선수의 포스트시즌 자격 판정.
- **[NOT-IN-MVP]** 3각 이상 트레이드, 현금 트레이드(규약상 양수도계약서 기재 시 합법이지만 초기 버전에서 제외).
- **위반 처리:** 기간 외 트레이드 = **BLOCKED** / 양도 금지 기간 선수 = **BLOCKED** / 트레이드 후 외국인 3명 초과 = **BLOCKED**.

### 4.6 신인드래프트 (KBO-OFFSEASON-006)
- **R1:** 라운드별 지명(11라운드 - 핵심 라운드만 직접 지명하고 나머지는 [자동 지명] 위임 가능).
- **R2:** 전년도 성적 역순 / 대졸 1명 이상 의무 지명 검증 / 계약교섭권 · 계약금 · 1년 양도 금지 / AI 구단 지명.
- **[GAME-SIMPLIFIED]** 현실 개최 시기는 시즌 중(통상 9월)이다. 게임 배치는 기획자 결정 사항(`KBO_RULE_DECISION_LOG.md` DECISION-006).
- **위반 처리:** 대졸 의무 지명 미충족 상태로 드래프트 종료 = **BLOCKED**.

### 4.7 보류선수 · 방출 (KBO-OFFSEASON-007, 011, 012)
- **R1:** 보류 명단에서 뺄 선수(방출) 결정.
- **R2:** 11월 25일 명단 · 11월 30일 공시 · 미보류 선수 자유계약 전환 / 원 소속 1년 재등록 금지 / 보류선수 63명 · 소속 68명 정원 검증.
- **R3:** 보류수당 일할 계산, 보류권 침해 재정.
- **위반 처리:** 정원 초과 = **BLOCKED** / 방출한 선수 1년 내 재영입 = **BLOCKED**.

### 4.8 외국인 · 아시아쿼터 (KBO-OFFSEASON-008)
- **R1:** 외국인 3명 + 아시아쿼터 1명 계약 · 재계약 · 교체.
- **R2:** USD 상한 검증(신규 100만 · 3명 합계 400만 · 재계약 연차 가산 · 아시아 20만) / 동일 포지션 3명 금지 / 동시 출장 3(+1)명 /
  추가등록 횟수(2회·1회) / 6주 부상 대체 / 8월 15일 이후 등록자 포스트시즌 불가 / 환율 적용 예산 차감.
- **위반 처리:** 슬롯 초과·동일 포지션 3명 = **BLOCKED** / USD 상한 초과 = **PENALTY**(초과분 50%~150% + 2라운드 지명권 하락).

### 4.9 선수 등록 (KBO-OFFSEASON-009, 015)
- **R2:** 1군 29명(출장 27명, 9월 34/32명) · 말소 후 10일 재등록 제한 · 부상자 명단 일수 · 등록일수 누적(FA 서비스 타임) 자동 처리.
- **R1:** 1군/퓨처스 이동은 시즌 중 단장이 하되, [자동 엔트리 관리]를 기본 제공.
- 포스트시즌 엔트리 30명(출장 28명)은 7월 31일 소속 기준 자동 검증.

### 4.10 연봉 · 중재 (KBO-OFFSEASON-013, 014)
- **R1:** 재계약 연봉 제시.
- **R2:** 최저연봉(2026 3,000만 / 2027~ 3,300만) 자동 적용 / 1월 31일 계약 마감 / 미합의 시 중재 자동 진행(만 3년 이상 선수만, 양측 제시액 중 하나로 결정).

## 5. 행정 절차 생략 목록 (R3)

현실에는 있지만 초기 버전에서 생략한다. 도움말·툴팁에 "실제로는 ~ 절차가 있다"는 설명을 남긴다.

- KBO 제출 서류(FA 신청서, 보류 명단, 계약서, 양수도계약서)와 서면·전화 통보
- 세금계산서 발행·수령, 지연이자(법정이자 + 20%)
- 공시 대기 일수(공시 후 2일·3일·7일 등) - 턴 안에서 즉시 처리
- 보류수당 일할 계산, 의료기록 제출, 이면계약 조사·자료 제출 요구
- 경조휴가, 올스타전 출장 거부 말소, 말소 유예 소급

## 6. 플레이어 피로도 방지 규칙

- 하루 단위로 날짜를 넘기는 행정 화면을 만들지 않는다(턴 단위).
- 보상률·이적료율 같은 비율 계산을 플레이어에게 시키지 않는다(결과 금액만 표시).
- 의무 등록 일수·FA 등록일수는 게이지로만 보여 준다.
- 규정 원문 탐색을 요구하지 않는다(툴팁 한 문장 + 필요 시 [규정 보기]로 원문 요약).
- 모든 BLOCKED·WARNING은 실행 **전에** 알린다(실패 후 알림 금지).
