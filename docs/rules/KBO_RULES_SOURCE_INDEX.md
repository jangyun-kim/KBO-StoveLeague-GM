# KBO Rules Source Index

> 문서 세트: `docs/rules/` · `docs/design/` · `docs/handoff/` (10종, 2026-10-07 작성)
> 최우선 규칙은 프로젝트 `CLAUDE.md`이며, 이 세트는 스토브리그(오프시즌) 현실 규정의 **원형 보존 + 게임 적용 근거**를 관리한다.

## 1. 문서 목적

스토브리그 시스템을 구현할 때 기준이 되는 KBO 공식 규정집의 출처를 관리한다.
공식 규정 원문은 그대로 보존하고, 게임에 적용할 때 어느 조항·어느 페이지를 근거로 했는지 추적한다.

**페이지 표기 규칙:** `인쇄 p.N`은 규정집 본문 하단에 찍힌 쪽 번호, `PDF p.M`은 PDF 뷰어의 페이지 번호다.
- `2026_KBO_야구규약.pdf`: PDF 페이지 = 인쇄 페이지 + 8
- `2026_KBO_리그규정.pdf`: PDF 페이지 = 인쇄 페이지 + 12
