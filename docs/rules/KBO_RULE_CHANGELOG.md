### 추가된 내용
- 웨이버(제93조~제103조), 자유계약 · 임의해지 · 복귀(제30조 · 제31조 · 제65조~제68조), 연봉 · 감액(제69조~제73조), 연봉 중재(제75조~제80조),
  포스트시즌 출장자격(리그규정 제45조: 7월 31일 소속 기준, 30명 등록 · 28명 출장), 육성선수(제116조~제117조).
- 페이지 표기를 `인쇄 p.` / `PDF p.` 두 가지로 통일(규약 +8, 리그규정 +12).
- Rule ID 표기 통일(`KBO-OFFSEASON-0NN`).
- 가이드북(DOC-KBO-003)을 규정 근거가 아닌 **선수 데이터 출처**로 분류.

## v0.1 (초안 - 기획 AI 작성분)

### 확정된 내용
- 스토브리그 일정을 8개 고정 Turn으로 분리.
- 2026년 샐러리캡 상한액(143억 9,723만 원) 및 2027년 하한액 도입.
- 2차 드래프트 격년제 · 35인 보호 · 1~3년차 자동 제외.
- 아시아쿼터(외국인 3 + 아시아 1) 별도 슬롯.
- 선수 상태 4축 분리(소속 · 등록 · 거래 · 자격).

### 변경된 내용
- 날짜 기반 일일 추적 폐지 → 턴제.
- 3각 이상 트레이드 · 현금 트레이드 초기 스펙 제외.
- 포스팅을 조건부 이벤트로.

### 보류된 내용
- FA 승인 후 3년 미계약 → 자유계약 전환 시 엣지 케이스(v0.2에서 원문 확인: 제169조 ③, 자유계약 공시 후 어느 구단과도 계약 가능).
- 2차 드래프트 의무 등록 미충족 선수가 재양도된 경우 양도금 50% 반환 주체(v0.2에서 원문 확인: **최초 2차 드래프트 양도·양수 구단 간**, 의무는 최종 양수구단, 제182조 ④).

### 다음 검증 대상
- 경쟁균형세 원 단위 절사·반올림 기준(원문 미기재 - 게임 정책으로 정해야 함).
- 하한액 구체 금액(이사회 공시 사항).
- 「한·일 선수계약협정」(NPB 포스팅) 매핑.
