# 릴리스 노트

## v0.2.0 - 치어리더 스토브리그 업데이트

치어리더 가챠 상점 시스템을 새로 도입하고, 데이터 파이프라인과 UI 편의성, 개발 툴링을 함께 정비한 v0.2 마일스톤이 마감되었습니다.

### 신규 기능
- **치어리더 가챠 상점 신설** - 프리미엄 재화로 1회/10회 뽑기를 진행할 수 있습니다. NORMAL / RARE / EPIC / LEGEND 4개 등급이 각각 70% / 22% / 7% / 1% 확률로 등장합니다.
- **CSV 기반 데이터베이스 연동** - 치어리더 종류와 능력치가 하드코딩이 아닌 데이터 파일(`cheerleaders.csv`)로 관리되어, 향후 콘텐츠 추가가 더 유연해졌습니다.

### 시스템 개선
- **중복 획득 시 재화 반환 시스템 적용** - 이미 보유한 치어리더를 다시 뽑으면 사라지지 않고, 등급에 따라 프리미엄 재화로 자동 환급됩니다.
- **UI 편의성 고도화** - 인벤토리/상점 화면에서 클러치 배율·팬심 방어력 등 치어리더의 세부 능력치를 직접 확인할 수 있고, 로비 화면에서 보유 재화를 바로 볼 수 있습니다.

### 개발자 도구
- **10,000회 확률 시뮬레이터 도입** - 실제 가챠 확률표(70/22/7/1)가 장기적으로 의도한 대로 수렴하는지 자동으로 검증할 수 있는 QA 도구가 추가됐습니다.
- **UI 원클릭 마스터 셋업 툴 추가** - 씬에 흩어져 있던 UI 패널들을 메뉴 클릭 한 번으로 전부 자동 연결합니다.
- **클린 씬 아키텍처(중복 매니저 제거) 적용** - 씬에 중복으로 존재하던 매니저 컴포넌트를 찾아 제거하는 핫픽스 툴을 도입했고, 관련 컴파일 경고를 모두 해소해 현재 에디터 코드베이스는 경고(Warning)/에러(Error) 없는 클린 빌드 상태입니다.
