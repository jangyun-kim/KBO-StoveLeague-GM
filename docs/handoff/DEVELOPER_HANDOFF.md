## 1. 구현 목표

KBO 스토브리그 규정을 현재 코드베이스에 어떻게 연결할지 조사 · 설계하고, 승인 후 단계적으로 구현한다.
조사 대상: 시즌 종료 · 다음 시즌 전환 / 스토브리그 Phase / 선수 계약 / FA 자격 · 계약 만료 / 구단 예산 / 경쟁균형세 /
선수 등록 · 말소 / 트레이드 / 드래프트 / 포스팅 / 선수 이동 기록 / 저장 · 불러오기 / 기존 테스트.

**승인 전 금지:** 코드 수정 · 신규 코드 작성 · 데이터 마이그레이션 · 규정값 하드코딩 · 상태 머신 구현 · UI 변경 · 저장 포맷 변경 · 리팩터링 · 테스트 추가.

## 2. 규정 적용 원칙

### 2.1 원형 보존
- 공식 규정은 Rule ID · 문서명 · 조항 · 인쇄/PDF 페이지 · 적용 시즌 · 원문 요약과 함께 `docs/rules/KBO_OFFSEASON_RULES.md`에 보존한다.
- 공식 규정과 게임 규칙을 한 로직으로 합치지 않는다: `공식 규정 값(연도별 테이블) → 게임 적용 정책 → 게임 상태 변화`.
- 규정 수치는 코드 상수로 흩뿌리지 않고 **연도별 규정 테이블**(`docs/design/OFFSEASON_DATA_SCHEMA.md` 1절) 한 곳에서 읽는다.

### 2.2 플레이어 의사결정 집중 (R1)
FA 영입 · 잔류, 계약 기간 · 금액, 트레이드(지명권 포함), 신인드래프트 지명, 2차 드래프트 보호선수 · 지명, FA 보상 방식 · 보상선수 선택,
외국인 · 아시아쿼터, 방출 · 보류선수 지정, 포스팅 승인/거절, 경쟁균형세 예외 선수 지정, 예산 배분.

### 2.3 시스템 자동화 (R2)
날짜 ↔ Turn 변환, FA 자격 · 등급, 보상금 · 보상 순서, 계약 승인, 등록 · 말소 · 등록일수, 2차 드래프트 의무 등록 · 예외, 포스팅 이적료,
경쟁균형세 산정 · 제재 · 지명권 하락, 소속 변경, 거래 이력, AI 구단의 FA · 트레이드 · 지명.

### 2.4 위반 처리
**BLOCKED**(불가) / **WARNING**(경고 후 진행) / **PENALTY**(진행 + 자동 제재). 규정별 분류는 `KBO_GAME_SIMPLIFICATION_POLICY.md` 4절.

### 2.5 행정 절차 생략 (R3)
제출 서류 · 세금계산서 · 계약서 원문 · 서면 승인 · 공시 문서 · 지연이자. 생략해도 "현실에는 있다"는 사실은 문서 · 도움말에 남긴다.

## 3. 규정 매핑 상태 정의

| 상태 | 의미 |
|---|---|
| IMPLEMENTED | 규정 또는 동등한 게임 기능이 구현됨 |
| PARTIAL | 일부 데이터나 로직만 구현됨 |
| MISSING | 관련 구현 없음 |
| CONFLICT | 기존 코드와 새 규정이 충돌 |
| UNKNOWN | 관련 코드를 찾지 못했거나 판단 정보 부족 |
| NOT_APPLICABLE | 현재 게임 범위에 적용하지 않기로 확정 |
| NEEDS_DESIGN | 코드보다 기획 결정이 먼저 필요 |

금지 표현: "완벽히 구현됨", "문제 없음", "구현하면 됨", "추후 알아서 처리". 근거 파일 · 코드 위치 없는 판정 금지.

## 5. 코드베이스 조사 요구 / 6. 가상 구조와 실제 구조 구분 / 7. 매핑 절차

- 파일 · 클래스 · 함수 이름을 추측하지 않는다. 실제 구조를 찾고, 예시 구조(`SeasonManager`, `ContractManager`, `TransactionManager` 등)는
  "실제 존재 / 유사 구조 / 이름 다름 / 분산 구현 / 없음 / 확인 불가"로 표시한다. **예상 구조가 없다고 새 클래스를 만들지 않는다**
  (프로젝트 `CLAUDE.md` 9절: 새 클래스를 중복으로 만들지 말고 기존 구조에 맞춘다).
- 매핑 절차: 관련 코드 찾기 → 실제 위치 기록 → 현재 동작 설명 → 매핑 상태 판정 → 코드 수정 없이 변경안(필요 데이터 · 로직 · 화면 · 저장 · 테스트 · 충돌 · 순서).

조사 결과는 `docs/handoff/OFFSEASON_PRE_INVESTIGATION_REPORT.md`에 아래 8절 양식으로 정리했다.
