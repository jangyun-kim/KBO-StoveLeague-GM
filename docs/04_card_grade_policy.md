# 3. 등급 인플레이션 방지 및 가치 보존 원칙

1. **[v0.4 개편] Salary = 개인 세트덱 스코어(샐러리 캡 폐기):** 구 샐러리 공식 `기본 코스트 + (최종 OVR-60) + (각성*1.5)`와 28인 샐러리 캡(1350/오토 라인업 300)은 TASK-KBO-173에서 삭제됐다. 카드의 Salary는 이제 곧 **역전 설계된 개인 세트덱 스코어**이며(5절, `cards_*.csv` `salary_cost` = 기본 스코어), 상위 등급 도배 방지는 "종결 카드일수록 스코어가 낮아 27인 세트덱 버프 구간을 잃는다"는 구조가 전담한다(10절).
2. **미구현 데이터 처리 (Forward Compatibility):** v0.1 빌드에서 가챠 로직은 `LIVE_NORMAL`/`LIVE_EPIC` 2개 Enum만 반환한다. `SaveManager`는 Grade 자체를 JSON에 저장하지 않으므로(`TemplateId`로 원본을 다시 찾는 구조) 등급 체계 개편은 기존 JSON 세이브 파일을 깨뜨리지 않는다. 저장된 `AwakenLevel` 10은 v0.3부터 "초월"로 해석되며, 초월 불가 등급의 레거시 10각은 계산 시 9각으로 클램프된다.
3. **[v0.3 폐기] 왕조 세트덱 +15 / 일반 세트덱 +12:** TASK-KBO-037/166의 "동일 구단 15명 이상 +12", "왕조 카드 5명 이상 +15" 판정은 6~7절의 **27인 세트덱 스코어 → 버프 구간** 체계로 완전히 대체됐다. DYNASTY는 이제 "단일 구단 세트덱일 때만 스코어 합산"이라는 PDF 규칙으로 차별화된다(6절).
4. **LIVE 초월의 OVR 상한:** LIVE는 초월까지 성장해 세트덱 스코어는 최대 8점을 주지만, 실전 성장치(강화+각성)는 ALLSTAR 최대치(10강 + 9각 = 세부 스탯 +19)로 잘린다 - 같은 선수의 LIVE 초월 카드는 ALLSTAR 9각 카드와 **동급 이하**의 Final OVR을 갖는다(`CardGrowthRules.MaxStatGrowthFor`, `Player.GetStatGrowth`). 초월의 가치는 오직 세트덱 스코어(+1)에 있다.

# 4. 각성 시스템 (1~9각 + 초월)

PDF "[각성 시스템 수정]": 기존 1~10각 → **1~9각 + 초월**. 기존 10각을 초월로 명칭 변경했으며, **9각에 도달한 LIVE, SIGNATURE, GOLDEN_GLOVE, DYNASTY에 한해서 초월 가능**하다(PDF 원문 - LIVE는 LIVE_NORMAL/LIVE_EPIC 모두). **[v0.5] RETIRED_NUMBER도 초월 가능으로 격상.** 초월 불가 등급(ALLSTAR/FRANCHISE/TITLE_HOLDER)은 9각이 한계다.

- **[v0.5] 각성 비용(재료 1장당 포인트, 초월 = 10):** LIVE는 완화 - 같은 카드 사본 +5 / 같은 선수·같은 등급 다른 카드 +2 → **LIVE 초월 = 사본 2장**. 그 외 등급 - 사본 +3 / 다른 카드 +1 → 초월 사본 4장, 9각 사본 3장(`CardGrowthRules.AwakenPointsPerMaterial`).

- 내부 저장값: `Player.AwakenLevel` 0~9 = n각, 10 = 초월(`CardGrowthRules.TranscendLevel`). 등급별 한계는 `CardGrowthRules.MaxAwakenLevelFor()`이며, `cards_*.csv`의 `max_awaken` 컬럼(초월 가능 10 / 9각 한계 9)과 일치한다.
- `UpgradeManager.TryAwaken()`은 등급별 한계에서 멈춘다. v0.2까지 각성 불가였던 LIVE도 이제 각성 가능하다.

# 5. 선수 개인 세트덱 스코어 = Salary (TASK-KBO-173 역전 규격)

**산술 규칙(유지):** 개인 스코어 = 등급 기본 스코어 + 3각(+1) + 6각(+1) + 9각(+1) → 9각 달성 시 기본 대비 **+3**. 초월 가능 등급은 초월 달성 시 추가 +1 → 기본 대비 **+4**.

**[v0.4 역전 밸런스]** "카드 성능(OVR)이 높을수록 개인 스코어는 낮게, 성능이 낮은 LIVE는 가장 높게(최대 8점)". 27인 최대 목표 200P(1인 평균 7.4점)에서 종결 카드(DYN/SIG/GG)만으로 도배해도 200P는커녕 1차 목표(150P)에도 닿지 못하게 하는 것이 목적이다(10절 검증).

| :-- | :-: | :-: | :-: | :-: | :-: | :-: | :-: |
| LIVE (LIVE_NORMAL / LIVE_EPIC) | O | 4 | 5 | 6 | 7 | **8** | 8 (+4) - 유일한 8점 공급원 |
| ALLSTAR (AS) | X | 4 | 5 | 6 | **7** | - | 7 (+3) |
| FRANCHISE (FRA) | X | 3 | 4 | 5 | **6** | - | 6 (+3) |

- 구현: `Models/CardGrowthRules.cs`(`BaseSetDeckScore` = Salary, `SetDeckScoreFor`), `Player.Salary`/`Player.SetDeckScore`. `GenerateKBODatabase.py`의 `SETDECK_BASE_SCORE`가 `salary_cost` 컬럼을 같은 값으로 생성하고, `PlayerDatabase`가 로드 시 불일치 카드를 경고한다.
- `RETIRED_NUMBER` **[v0.5 확정]**: 기본 2 → 3각 3 → 6각 4 → 9각 5 → 초월 6. 실전 성능은 SIGNATURE/DYNASTY 동급 최상위이면서 스코어는 그보다 +1 높다 - 구단별 1~4명뿐이라 도배가 불가능하므로 구단 덱의 핵심 주축(Core Captain)이 되도록 한 예외다(v0.4 잠정값 "2 → 9각 5" 폐기).
- **이력:** v0.3(TASK-KBO-172) 규격은 LIVE 4/8, AS 3/6, FRA·TH 4/7, GG 4/8, SIG·DYN 5/9였다(종결 카드가 더 높은 정비례 구조). PDF 원안은 특훈 lv.4/3각/9각/초월 단계에 LIVE_NORMAL 4/8, LIVE_EPIC 5/9, ALLSTAR 4/7, TITLE_HOLDER 4/7, SIGNATURE 4/8, GOLDEN_GLOVE 3/7, DYNASTY 4/8이었다.

# 6. 27인 세트덱 스코어 산정 규칙

PDF "[세트덱 스코어 시스템]" + "세트덱 스코어 제한사항"을 구현한 규칙이다(`Models/SetDeck.cs` `SetDeckEvaluator`).

1. **27인 구성:** 타자 선발 9명 + 후보 6명 + 투수 선발 5명 + 중계/마무리 7명 = 27인. 28인 로스터에서 주전 타자는 포지션별 최고 OVR, 후보 타자 6·선발 5·불펜 7은 각 그룹 OVR 순으로 선발한다(주전 21 + 후보 6 전원 합산).
2. **자팀 선수 필수:** 기준 구단(유저 = 선호 구단, 미지정/AI = 로스터 최다 구단) 소속 카드만 합산한다. **예외: GOLDEN_GLOVE는 소속 구단 무관 합산.**
3. **DYNASTY 단일 구단 조건:** 27인 중 GOLDEN_GLOVE를 제외한 다른 구단 카드가 한 장이라도 있으면 DYNASTY 스코어는 합산하지 않는다(PDF: "소속구단 단일에만 적용. 다른 구단 선수가 있을 경우 미적용").
4. **LIVE 카드 활용:** 뉴비 구간에서는 스코어가 높은 LIVE 카드를 적극 기용해 초반 세트포스트 점수를 빠르게 확보해야 오버롤 격차를 줄일 수 있다(PDF 원문) - LIVE 초월 8점은 후보 6인 슬롯 등에 넣는 "스코어 배터리"다.
5. **표시:** 홈-라인업 창 하단의 세트효과 아이콘(구단 마크)에서 확인(PDF). 현재 구현은 로스터 화면 게이지(200P 대비 진행률)와 시너지 패널 요약 문구(`SetDeckUIText.Summary`: 현재 스코어, "모든 능력치" 누적, 다음 목표 단계와 남은 점수).

## 8-3. 해설 - 과금 영역별 차별화 논리 (v0.4)

1. **보유 한계 = 기용 의무가 아니다.** PDF 표는 "풀성장 라인업에 기용할 수 있는 최대"다. 역전 규격에서는 프리미엄을 전부 기용할수록 스코어가 떨어지므로, 과금이 높을수록 "어떤 종결 카드를 주전 몇 자리에 쓰고, 나머지를 AS/LIVE로 채울지"를 고르는 **편성 선택지**가 넓어지는 방향으로 차별화된다(10-3절의 기용 상한).
2. **무·소과금은 LIVE 초월로 세트덱 최상위 구간을 노린다.** LIVE가 유일한 8점 공급원이라 무과금도 LIVE 육성만으로 핵심~최종 구간에 닿는다(시간 대 과금 교환).
3. **과금 유저의 이점은 주전 경기력이다.** 종결 카드는 스코어를 1~3점 덜 주는 대신 주전 슬롯의 실전 능력치를 올린다. 200P 버프(모든 능력치 +16)와 종결 카드 경기력 사이의 교환이 핵심 의사결정이다.
4. **DYNASTY 인플레이션 억제:** 24장뿐 + 단일 구단 덱에서만 합산 + 최대 5점.

## 8-4. 주의 사항 및 결정 필요 (v0.4)

## 11-4. 카드 등급별 실전 능력치(base_ovr) 연동

- **생성:** `base_ovr = 선수 기본 OVR + 등급 보정`. 선수 기본 OVR은 players.csv z값의 `z×15+50` 환산(PlayerDatabase와 동일), 등급 보정은 LIVE_NORMAL +0, LIVE_EPIC +1, ALLSTAR +3, FRANCHISE +4, TITLE_HOLDER +5, GOLDEN_GLOVE +7, SIGNATURE/DYNASTY/RETIRED_NUMBER +10(`GRADE_OVR_BONUS` = `CardGrowthRules.GradeOvrBonus`). 예전 base_ovr는 등급별 무작위 범위라 범위가 겹쳤다(같은 선수의 TH가 GG보다 높을 수 있었음) - 결정론으로 바꿔 **같은 선수 서열 LIVE < AS < FRA ≤ TH < GG < SIG = DYN = RN을 전 카드에서 보장**한다(검증: 위반 0건).
- **런타임:** `PlayerDatabase`가 카드마다 선수 기본 스탯 전 항목을 `(base_ovr - 선수 기본 OVR)`만큼 균등 이동 → 카드 기본 OVR = base_ovr, 경기 세부 스탯과 라인업 OVR에 그대로 반영된다. 이후 강화/각성 성장치가 더해진다(LIVE는 성장 상한 +19 = ALLSTAR 9각 동급).
- **동일 선수 비교(명함 → 풀성장):**

| 선수 | LIVE | ALLSTAR | TITLE_HOLDER | GOLDEN_GLOVE | SIGNATURE | DYNASTY | RETIRED_NUMBER |
| :-- | :-: | :-: | :-: | :-: | :-: | :-: | :-: |
| 구자욱 | 78 → 97 (초월) | 81 → 100 (9각) | 83 → 102 | 85 → 105 (초월) | 88 → 108 | - | - |
| 선동열 | - | - | 81 → 100 | 83 → 103 | 86 → 106 | 86 → 106 | 86 → 106 |
| 오승환 | - | 57 → 76 | 59 → 78 | - | 64 → 84 | 64 → 84 | 64 → 84 |

  LIVE 초월(97)은 같은 선수 ALLSTAR 9각(100)보다 낮다 - "LIVE 초월 ≤ AS 9각" 제약 충족.
- **[주의] 선수 간 비교는 보장되지 않는다:** 역대 실존 인물 상당수(오승환 기본 54, 최형우 DYN 56 등)는 등록 당시 재능치(z)가 무작위로 배정돼, 레전드 종결 카드가 평범한 선수의 LIVE보다 약할 수 있다. 실존 레전드 재능치 보정은 후속 과제다(DCL-145).

## 11-5. LIVE 각성/초월 비용 확정

| 재료 | LIVE | 그 외 등급 |
| :-- | :-: | :-: |
| 같은 카드 사본 1장 | +5 | +3 |
| 같은 선수·같은 등급 다른 카드 1장 | +2 | +1 |
| 초월(10)까지 필요한 사본 | **2장** | 4장 (9각 한계 등급은 3장) |

무과금 연간 LIVE 약 10장 초월 = 사본 약 20장. 이 경우 27인에 LIVE 초월 10장 + 나머지 LIVE 6각 7장 + 무과금 한계 프리미엄 10장(풀성장)이면 10×8 + 7×6 + (SIG 4×5 + TH 2×6 + AS 4×7) = 80 + 42 + 60 = **182P**, SIG 4장 대신 LIVE 6각 4장을 쓰면 186P(핵심 185P), 나아가 프리미엄을 AS 9각 4장만 남기고 나머지 LIVE 13장을 9각까지 키우면 10×8 + 13×7 + 4×7 = 199P(핵심 190P) - 편성과 LIVE 육성도에 따라 **185~190P 핵심 구간**에 도달한다. 연간 LIVE 영입 횟수(재화 수급량) 자체는 아직 정의되지 않아 사본 20장 확보 가능 여부는 경제 설계에서 확인해야 한다.
