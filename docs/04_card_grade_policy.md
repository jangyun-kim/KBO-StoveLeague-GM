# 3. 등급 인플레이션 방지 및 가치 보존 원칙

1. **샐러리캡 절대 복종:** 상위 등급 카드가 무조건 이기는 구조를 막기 위해, 아무리 좋은 카드라도 샐러리 비용 공식 `기본 코스트 + (최종 OVR-60) + (각성*1.5)`에 종속된다. 왕조 카드로 도배하면 구단 예산 파산 또는 리그 등록이 불가능하다.
2. **미구현 데이터 처리 (Forward Compatibility):** v0.1 빌드에서 가챠 로직은 무조건 0~2번 Enum만 반환하도록 하드코딩한다. v2.0에서 7번(왕조)이 추가되어도 기존 유저의 0~2번 카드 데이터 직렬화(JSON)는 깨지지 않는다.
