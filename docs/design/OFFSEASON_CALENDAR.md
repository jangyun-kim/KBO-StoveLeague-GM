# Offseason Calendar (스토브리그 캘린더 모델)

현실 날짜를 게임 Turn으로 바꿔 진행 흐름을 고정한다. 날짜는 화면에 "11월 중순"처럼 참고로만 보여 주고, 진행 단위는 Turn이다.

## 1. 일정 데이터 구조

| 항목 | 의미 | 타입 |
|---|---|---|
| `rule_date` | 규약에 명시된 기한(예: 11월 25일 보류명단) | 월-일 또는 상대일(예: KS 종료 + 5일) |
| `official_date` | 그해 KBO가 실제 공시한 날짜 | 날짜(없으면 null) |
| `game_turn` | 게임 Turn(1~8) 또는 `IN_SEASON` | 정수 / enum |
| `relative_phase` | 스토브리그 내 단계 | enum |
| `status` | `confirmed`(규약 명시) / `season_announced`(시즌별 공시) / `open_question`(미확정) | enum |
| `rule_id` | 근거 Rule ID | 문자열 |
