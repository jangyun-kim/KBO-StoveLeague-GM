## 1. 콘셉트 · 핵심 루프

프런트 오피스 협상 · 정치 시뮬레이션. 정규시즌은 자동 시뮬레이션 중심이지만 스토브리그에서 세운 기용 · 육성 · 계약 · 전력 구성의 결과를 생성하고 검증하는 단계다.

```
정규시즌 144경기(실시간 대시보드) → 시즌 결산실(성적 · 재정 · 약점 진단) → 포스트시즌 → 시상식 → 해 넘김
→ 선수단 회의실(관계 · 불만) → 계약 협상실(만료자 · 연봉) → 시장 정보실(FA · 트레이드) → 육성 회의실(퓨처스 · 드래프트)
→ 구단주 보고실(최종 로스터 · 목표) → 다음 정규시즌 → 결과가 다음 스토브리그의 예산 · 사건으로 연결
```

## 2. 스토브리그 8 Turn · 7개 콘텐츠실

- [TASK-GM-14] 8 Turn 진행 통제 구현(`GMStoveTurns`): Turn 대표 방(결산실 → 회의실 → 보호 명단 → 협상실 → FA → 선수단 → 드래프트 → 메인 홈)을 연 뒤 메인 홈 [진행하기]로 다음 Turn. 해금은 누적, 해금 전 방은 잠금 화면 + 실행 차단.
  Turn 2는 미해결 라커룸 사건 · 1군 정원 초과, Turn 8은 정원 초과 시 진행 불가. 2차 드래프트(Turn 3)는 홀수 해만 열리고(전용 UI는 3단계) 그 밖 해는 자동 통과. 8 Turn 완료 후 개막전 전력 분석.
- 2차 드래프트 35인 보호는 현재 로스터(1군 29 + 퓨처스 12)에서 의미가 없으므로 3단계에서 보호 인원 비율 축소안으로 다시 설계한다.

## 3. 프런트 직원(MVP 3인)

데이터분석팀장(성과 · 세이버 · 약점 · 대체 가치) · 재무팀장(예산 · 캡 여유 · 적정 연봉 · 경쟁균형세 경고) · 선수관리팀장(유대 · 충성도 · 불만 · 협상 성향).

## 4. 성과 리포트 · 지표

### 4.1 색상 코딩(새 결산 · 협상 화면 기준)

빨강 = 강점 · 높음 · 유리 / 초록 = 보통 · 중립 / 파랑 = 약점 · 낮음 · 주의 / 주황 = 위험 · 변동성 · 추가 확인.
(기존 허브 화면의 초록 = 좋음 표기는 그대로 두고, 두 화면 상단에 범례를 표시한다.)

### 4.2 게임용 대체 지표(TASK-GM-11 구현)

| 원 지표 | 게임 지표 | 산식 | 등급 |
| --- | --- | --- | --- |
| WAR | 종합 기여도 | `GMLiveSeasonSimulator.UpdateWar` 간이 WAR(타자 wRAA + 대체 수준 + 도루 / 투수 FIP 기반) | 시즌 비중 f 반영: 3.0f 이상 빨강 · 1.0f 미만 파랑(불펜 1.5f / 0.3f), 0.2f 이하 = "대체 선수 수준" |
| wRC+ | 타격 생산성 | 100 + 200 × (wOBA ÷ 리그 wOBA − 1) | 115↑ 빨강 · 90 미만 파랑 |
| FIP | 투수 독립 기여도 | 100 + 200 × (리그 FIP − FIP) ÷ 리그 FIP, FIP = (13HR + 3BB − 2K) ÷ 이닝 + 상수(리그 4.30) | 같음 |
| UZR | 수비 기여도 | 100 + 100 × (경기당 수비 점수 − 리그 평균) ÷ 리그 평균 | 115↑ 빨강 · 85 미만 파랑 |
| - | 연봉 효율 | WAR × 리그 1WAR당 연봉 ÷ 연봉 | 1.3배↑ 빨강 · 0.7배 미만 파랑(최저 연봉권은 초록) |
| - | 대체 불가성 | 내 WAR − 최선의 대안(같은 포지션 · 보직 구단 백업 · FA) | +1.5f↑ 빨강 · +0.5f 미만 파랑 |
| - | 최근 추세 | 실제 WAR − 출전 비중 반영 OVR 예상 WAR | ±0.8, 34세+ = 주황(노쇠 위험), 부상 = 주황 |

"WAR 0"은 공격력이 아니라 종합 기여도가 대체 선수 수준이라는 뜻이다. 타격만 말할 때는 "타격 생산성"으로 쓴다.

신뢰도: 타자 300타석(× f) 이상 높음 · 120 이상 보통 · 그 미만 낮음 / 투수 선발 80이닝 · 불펜 40이닝 이상 높음 · 25이닝 이상 보통. 추정치는 항상 낮음 + 표본 부족.

### 4.3 기록 출처

① 진행 중/종료된 정규시즌 기록 → ② 정규시즌 종료 시(`GMFrontOffice.OnSeasonCompleted`) 남긴 전 구단 스냅숏(`GMFrontOfficeState.LastSeasonReview`, 세이브 v22 - 연도 전환으로 Stats가 비워진 뒤 Turn 1 결산 · 협상 근거) → ③ 추정.

## 5. 선수단 다이내믹스

파이프라인: `개인 성향 → 선수 간 유대 → 구단 충성도 → 팀 분위기(= 팀워크) → 협상 성공률 / 경기 안정성` (중복 적용 금지).

- **유대(`GMPlayerBonds`):** 배터리(주전 포수 ↔ 1~5선발) · 키스톤(주전 2루수 ↔ 유격수) · 멘토(더그아웃 리더 31세+ ↔ 같은 투타 유망주). 경기 OVR 보정 없음.
- **구단 충성도(`Player.Loyalty`, 0~100):** 기본 50 + 라커룸 성향(리더 +12 · 살림꾼 +6 · 유망주 +4 · 알파독 −6 · 야망가 −8) + 주장 +5 + 에이전트(충성형 +15 · 금전 우선 −10) ± 해시 8. 협상 결과로 변한다.
- **에이전트 성향(`Player.AgentArchetype`):** 현실형 · 충성형 · 장기계약 선호 · 금전 우선 · 보직 중시 · 우승 지향 - 라커룸 성향별 후보 2~4개 중 RealPlayerId 해시로 고정(33세+ 장기계약 선호 후보 추가).
- **팀 분위기:** 기존 팀워크(실효 전력 0.80~1.15) 그대로.

## 6. 조건부 연봉 협상(계약 협상실)

1. 후보 풀: 리포트 · 나이 · 유대 · 재정으로 유효한 카드 5~7장(모자라면 범용 카드로 채움).
2. 제시: 서로 다른 분류(성과 · 재정 · 관계 · 보상)를 우선해 3장(재현 가능한 시드).
3. 카드 10종: 성적 하락 근거 · 기여도 인정/시장가 비교 · 샐러리캡/예산 한계 공개 · 연봉 효율 비교표 · 핵심 동료 유대 강조 · 프랜차이즈 상징 대우 · 우승 목표 호소 · 장기계약 보장(+1년) · 주전/보직 보장 · 성적 옵션 계약.
4. 확률:
   - 베이스라인 진행 가능성 = 0.45 + (만족도 − 70) × 0.004 + (충성도 − 50) × 0.003 + (선수단 신뢰도 − 60) × 0.002 + (팀워크 − 75) × 0.002 − (Ego − 3) × 0.03 − (난이도 배수 − 1) × 0.3 → 0.15~0.85
   - 카드 진행 가능성 = 베이스라인 + 0.10 × 성향 배수(0.5~1.5) → 0.05~0.95, 결렬 위험 = 1 − 진행 가능성
   - 결과 분포(요구액 수용 / 소폭 인상 / 동결 / 삭감): 종합 기여도 등급 기준선(강점 40/33/20/7 · 보통 28/34/28/10 · 약점 15/25/35/25, Ego 4+ 수용 +5) + 카드 이동량 × 성향 배수 → 정규화
   - 결과 연봉: 요구액(현재 +5% 이상) / 현재 + 차액 40% / 동결 / −10%
5. 재무팀장 경고: 요구액 수용 시 페이롤이 캡을 넘으면 주황, 캡 여유 10% 미만이면 파랑, 계약금(총액 10%)이 운영 자금보다 크면 주황.
6. 결렬: 쿨다운(그 스토브리그 재협상 불가, 해 넘김 시 해제) · 만족도 −6 · 충성도 −4 · 선수단 신뢰도 −2 · 에이전트 루머 소식(타 구단 역제안 · Ego 4+ & 충성도 45 미만이면 트레이드 요청설).
7. 타결: 만족도 수용 +8 / 소폭 +4 / 동결 −2 / 삭감 −6, 충성도 +4 / +2 / 0 / −5(반감 카드 −2 추가), 선수단 신뢰도 +1.
8. 동료 연봉 연쇄(TASK-GM-14 구현 `GMSalaryChain`): 계약 협상실 타결 · 재계약 시 - 대폭 인상(+20%이면서 +5,000만 원 이상) = 유대 동료(최대 2명) 충성도 +2 ·
   유대가 없는 같은 유형 동급 동료(OVR -3 이내 · 새 연봉보다 적게 받음, 최대 3명) 상대적 박탈감 충성도 -3(자존심 4+ -5) · 만족도 -3 / 삭감 타결 = 유대 동료 충성도 -2. 효과가 있으면 소식 1건.

## 7. 약속 시스템(2단계)

`PROPOSED → ACTIVE → FULFILLED | BROKEN`. 제안 시 달성 난이도 · 실패 위험도 고지. 위반 페널티는 기간제(예: 충성도 −25 · 선수단 신뢰도 −10, 2시즌)이고 다음 약속 이행 · 개인 면담 · 성적 개선으로 회복한다. 1단계의 "주전 · 보직 보장" 카드는 약속 예고 문구만 남긴다.

## 8. 동적 사건(2단계)

즉시 · 연쇄 · 배경 사건. `조건 → 후보 → 우선순위 → 중복 · 쿨다운 → 턴당 핵심 1 + 보조 2`. 1티어 예: 중심 타선 연봉 갈등.

## 11. 화면(TASK-GM-11)

프런트 오피스 서브 탭(1단 탭 0번, 6칸 → 8칸): ⑦ 시즌 결산실(`GMSeasonSummaryView` 화면) · ⑧ 계약 협상실(`GMNegotiationRoomView` 화면).
정규시즌 144경기가 끝나면 [진행하기]가 포스트시즌 트리보다 먼저 시즌 결산실을 연다(시즌당 1회, `GMFrontOfficeState.SeasonReviewSeenYear`).
결산실 선수 행을 누르면 그 선수로 계약 협상실이 열린다.
