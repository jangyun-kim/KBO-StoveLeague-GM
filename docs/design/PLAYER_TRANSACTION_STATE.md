# Player Transaction State (선수 이동 및 상태 모델)

선수 상태를 enum 하나로 관리하지 않고 **4개 축(소속 · 등록 · 거래 · 자격)**으로 나눠, 제도적 제약과 예외를 동시에 추적한다.
여기에 **제약 타이머**(1년 양도 금지 · 재등록 금지 등)를 별도 목록으로 둔다.

> 현재 코드: `Player`(`Assets/Scripts/Models/Player.cs`)에는 이 축이 없다. 소속은 "어느 `GMTeamState.Roster`에 들어 있는가 / `GMLeagueState.FreeAgents`에 있는가"로만 표현되고,
> 등록 상태는 `InjuryRemainingDays > 0` 여부뿐이다. 자세한 차이는 사전 조사 보고서 5절.

## 1. 소속 상태 (Affiliation)

| 값 | 화면 표기 | 의미 | 근거 |
|---|---|---|---|
| `UNDER_CONTRACT` | 계약 중 | 구단과 정식 계약(보류선수 포함) | 제40조 · 제56조 |
| `RESERVED_UNSIGNED` | 미계약 보류 | 보류됐으나 다음 연도 계약 미체결(1/31까지) | 제44조 ② · 제62조 |
| `FREE_AGENT` | FA | FA 승인선수(보상 규정 적용 대상) | 제167조 |
| `FREE_CONTRACT` | 자유계약 | 방출 · 보류 제외 · FA 3년 미계약 등(보상 없음) | 제30조 · 제61조 · 제169조 ③ |
| `VOLUNTARILY_RETIRED` | 임의해지 | 1년 경과 후 원 소속 복귀만 가능 | 제31조 · 제66조 |
| `OVERSEAS` | 해외 진출 | 포스팅 · 해외 FA | 제104조 |
| `RETIRED` | 은퇴 | | |

> 초안의 `RELEASED`는 현실 용어로는 `FREE_CONTRACT`(자유계약)와 같다. 보상 규정 적용 여부가 달라 `FREE_AGENT`와 분리한다.

## 2. 등록 상태 (Roster)

| 값 | 화면 표기 | 의미 | 서비스 타임 |
|---|---|---|---|
| `ACTIVE_ROSTER` | 1군 | 현역선수(29명, 9월 이후 34명) | 인정 |
| `INJURED_LIST` | 부상자 명단 | 10 · 15 · 30일, 시즌 최대 30일 | **인정** |
| `FUTURES_ROSTER` | 퓨처스 | 소속선수, 1군 미등록 | 불인정 |
| `REHAB_LIST` | 치료·재활 | 소속 · 육성 대상, 최소 10일 | 불인정 |
| `DEVELOPMENT` | 육성 | 정원 68명 외, 5월 1일 이후 소속 전환 가능 | 불인정 |
| `MILITARY_RESERVE` | 군보류 | 정원 외 | 불인정 |
| `NONE` | 미등록 | 소속 없음 | - |

> 초안의 `REHAB_LIST`(부상자 명단 겸용)를 **부상자 명단(등록일수 인정)**과 **치료·재활 명단(불인정)**으로 나눴다(리그규정 제14조 3·4호).
> FA 서비스 타임과 2차 드래프트 의무 등록 면제 판정이 둘에서 다르게 동작하기 때문이다.

## 3. 거래 상태 (Transaction)

| 값 | 의미 |
|---|---|
| `NONE` | 제약 없음 |
| `FA_ELIGIBLE` | FA 자격 공시됨, 신청 대기(공시 후 2일 - 게임은 Turn 1 안에서 자동 판정) |
| `FA_PENDING` | FA 승인, 계약 대기 |
| `TRADE_PENDING` | 트레이드 협상 중 |
| `WAIVER_PENDING` | 웨이버 공시, 7일 양수 대기 |
| `POSTING_PENDING` | 포스팅 중(30일 교섭) |
| `COMPENSATION_PENDING` | FA 보상 절차 진행 중(획득 구단은 보상 종료까지 신분 공시 요청 불가) |

## 4. 자격 상태 (Eligibility)

| 값 | 의미 |
|---|---|
| `ELIGIBLE` | 정상 |
| `INELIGIBLE` | 계약 공시 전 · 말소 후 10일 미경과 등 일시 불가 |
| `SUSPENDED` | 출장정지 |
| `DISQUALIFIED` | 실격(유기 · 무기 · 영구) |
| `RESTRICTED` | 제한선수(개인 사유) |
| `POSTSEASON_INELIGIBLE` | 7/31 이후 이적 · 8/16 이후 외국인 등록 · 8/1 이후 웨이버 이적 |

## 5. 제약 타이머 (Restrictions) - 축과 별개로 여러 개 동시 보유

| 제약 | 기간 | 근거 |
|---|---|---|
| 외부 FA 양도 금지 | 계약 후 1년 | 제174조 |
| 2차 드래프트 지명 선수 양도 금지 | 계약 후 1년(의무 등록 충족 · 3R 이하 예외) | 제181조 ③ |
| 2차 드래프트 의무 등록 | 다음 또는 그다음 시즌, 1R 50일 · 2R 30일 | 제182조 |
| 지명 신인 양도 금지 | 계약 후 1년(선수 대 선수 교환 예외) | 제115조 |
| 지명권으로 받은 신인 양도 금지 | 입단 후 1년 | 제84조 ④ |
| 방출 선수 원 소속 재등록 금지 | 보류명단 공시일부터 1년 | 제61조 ② |
| 말소 후 재등록 금지 | 10일 | 규약 제27조 |
| 웨이버 양수 선수 재웨이버 금지 | 60일 | 제102조 |
| 임의해지 복귀 신청 불가 | 1년 | 제66조 |

## 6. 상태 변경 예시

- **FA로 타 팀 이적:** 원 소속 `UNDER_CONTRACT` → `FREE_AGENT` + `FA_PENDING` → 새 팀 `UNDER_CONTRACT`, 새 팀 거래 상태 `COMPENSATION_PENDING`(보상 종료까지),
  제약 타이머 "외부 FA 양도 금지 1년" 추가.
- **보상선수 지명:** 지명된 선수 원 소속 → FA 획득 구단의 원 소속구단으로 `UNDER_CONTRACT` 이동(이적 거부 시 `VOLUNTARILY_RETIRED` + 3시즌 활동 금지).
- **2차 드래프트 지명:** 기존 팀 → 새 팀 `UNDER_CONTRACT`, 제약 타이머 "의무 등록(1R 50일)" · "양도 금지 1년" 추가.
- **보류 제외(방출):** 11/30 `FREE_CONTRACT`, 원 소속에 "재등록 금지 1년" 타이머.
- **부상:** `ACTIVE_ROSTER` → `INJURED_LIST`(서비스 타임 계속) 또는 장기 부상이면 `REHAB_LIST`(서비스 타임 중단).
- **포스팅 성사:** `UNDER_CONTRACT` → `POSTING_PENDING` → `OVERSEAS`, 원 소속에 이적료 편입.
