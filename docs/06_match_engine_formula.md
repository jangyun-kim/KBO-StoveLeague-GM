# 1. 목적

- 실제 선수의 Raw Data(스탯티즈 기반)를 게임 내 1~99 OVR로 변환하는 규칙과, 이 OVR이 시뮬레이션(Play-by-Play)에서 작동하는 롤(Roll) 확률을 명세한다.

# 2. 선수 스탯 변환 공식 (Z-Score & Bayesian)

모든 스탯은 리그 평균 대비 해당 선수의 Z-Score를 기반으로 산출한다.

- **베이지안 소표본 보정:** `보정 기록 = (선수기록 * 선수PA + K * 리그평균) / (선수PA + K)`
  - 타자 K상수: [TBD] (예: 300PA)
  - 투수 K상수: 선발 [TBD] IP, 불펜 [TBD] IP
- **최종 OVR 정규화 공식:** `OVR = MAX(40, MIN(99, ROUND(70 + (Z-score * 10), 0)))`

# 3. 6대 표시 스탯 매핑 규칙

| 게임 내 스탯        | 타자 원시 지표 (가중치)      | 투수 원시 지표 (가중치)                |
| :------------------ | :--------------------------- | :------------------------------------- |
| **정확** (제구1)    | Contact% (60%) + BABIP (40%) | BB% 역방향 (70%) + Zone% (30%)         |
| **선구** (제구2)    | IsoD (70%) + BB/K (30%)      | O-Swing% (60%) + K/BB (40%)            |
| **파워** (구위)     | ISO (60%) + HR/PA (40%)      | K% (50%) + IsoP 역방향 (50%)           |
| **주력** (수비기동) | SB Value (60%) + XBT% (40%)  | 도루저지율 기여도 (100%)               |
| **수비** (처리)     | FPCT (50%) + RF9 (50%)       | FPCT (50%) + P-UZR (50%)               |
| **체력** (이닝)     | PA/G (100%)                  | SP: IP/GS (100%), RP: 시즌총 IP (100%) |

# 4. 경기 엔진 확률 공식 (Logistic Probability)

- 1타석 결과는 난수 시드 기반으로 도출되며, 기본 예상 승률(안타 칠 확률 등)은 로지스틱 함수를 따른다.
- **예상 승리(안타) 확률:** `WinRate = 1 / (1 + 10^(-(타자 OVR - 투수 OVR) / 30))`
- **예외 처리:** 구단 버프, 치어리더 버프 등 외부 시너지가 개입할 경우 확률 굴림(Dice) 전 최종 OVR에 버프를 가산(+X)한 후 로지스틱 공식에 대입한다.
