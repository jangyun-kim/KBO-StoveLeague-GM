# 1. 핵심 플레이 루프 (Core Loop)

1. **스토브리그 (Decision):** 예산 확인 → 코칭스태프/치어리더 영입 → FA/트레이드 선수 영입 → 샐러리캡 최적화
2. **시즌 시뮬레이션 (Simulation):** 일일/주간/월간 캘린더 진행 → 2.5D 텍스트+하이라이트 중계로 데이터 검증
3. **결산 (Resolution):** 최종 성적 보상 + 치어리더/팬심 기반 흥행 수익 정산 → 선수 가치 변동
4. **순환:** 정산된 예산을 바탕으로 다음 스토브리그 진입

# 2. 디자인 필러 (Design Pillars)

1. **결과는 데이터로 (Data-Driven):** 승패는 과금액이 아닌 Z-score 기반 통계 엔진과 샐러리캡 최적화 지략으로 결정된다.
2. **단장의 시선 (GM's Perspective):** 플레이어는 무전기로 투수를 교체하지 않는다. 시스템과 스쿼드, 기조를 세팅하고 VIP석에서 결과를 지켜본다.
3. **경제와 팬심의 일체화 (Fandom Economy):** 치어리더와 홈경기 흥행은 단순 버프가 아니라, 다음 FA 선수를 사기 위한 '예산'을 벌어오는 경제적 심장이다.
4. **파괴 없는 누적 (Safe Progression):** 확률적 실패나 카드 파괴 스트레스 없이, 성장과 수집은 반드시 누적된다.

# 3. Non-Goals (절대 하지 않을 것)

- 컴투스프로야구V26처럼 1구 단위의 수동 타격/투구 피지컬 액션을 요구하지 않는다.
- 무조건 높은 등급의 카드로만 28인을 채우는 P2W 덱 구성을 허용하지 않는다 (샐러리캡 통제).
- 치어리더를 전투력(OVR) 뻥튀기용 펫(Pet)으로 소모하지 않는다.
